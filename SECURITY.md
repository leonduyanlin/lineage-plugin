# Security

The files currently published here are explicitly labeled unsigned previews. Windows cannot authenticate their publisher.

Before installation, obtain all matching-version files from this repository and validate them against `SHA256SUMS.txt`. Do not install a package whose hash, version, filename set, or preview notice differs.

Never download Lineage certificates, private keys, or alternative installers from this repository. None are distributed here. Do not post workbook contents, credentials, signing information, or exploit details in a public issue.

Signed production will use a separate stable publisher identity and stricter release gate when configured.
